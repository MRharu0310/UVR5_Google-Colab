# UVR5_Google-Colab
Separate vocals and instruments from an audio file using UVR5's BS-Roformer on Google Colab.

1. UVR5_Google-Colab.ipynbを開いて、一番上の「Open In Colab」を押すと作業ページに飛ぶ
2. 右上の「接続」の右側にある▼を押した後、「ランタイムのタイプを変更」から 「Python3, T4 GPU, 最新Ver.」を選択する
3. 「接続」を押して緑になるまで待つ
4. 抽出後の音声ファイルを各楽器にさらに分離する時は一番上のコードでENABLE_6STEMをTrueにする
5. 「すべてのセルを実行」を押す
6. 「5. 音声のアップロード」まで進むとファイルのアップロードができるようになるので、使用するWAVファイルを選択する
7. 最後にダウンロードの許可を求められるかもしれないので、その時は許可する


※ノイズ除去と音量の波の処理は実行するか選択可能

※無料枠には限りがあるので、上限が来たら12~24時間待つ必要あり（1度に3時間程度使える）
